A CRITICAL DISTINCTION

Workflow or agent?

A workflow follows a path written by code. An agent chooses the next step from the evidence it observes.

Code controls the path.

Predictable and explicit. Excellent when the sequence is known in advance.

502→Check NGINX→Check backend→Restart→Test
03 / 2024 · THE AGENT WAVE

The model started choosing what to do next.

An agent combines reasoning with executable tools and observations. It loops until the goal is complete, a boundary is reached, or a human must decide.

CapabilityAI could decide and act.
Reason → Act → Observe → Continue or Stop
ONE INCIDENT · STAGE 3

“Keep my website healthy.”

The agent checks health, inspects the proxy, follows the evidence, proposes a change and stops when success or a safety boundary is reached.

Result → Bounded action

05 / 2026 · HARNESS & RUNTIME

Autonomy needed an engineered place to run.

The harness surrounds the agent with context management, durable state, sandboxing, permissions, validation, recovery, evals and observability.

OPTIONAL COMPLEXITY

Interoperability is not a new intelligence level.

MCP connects systems to tools and context. A2A connects agents to agents. Multi-agent architectures are useful when specialization or parallel work justifies their complexity — not simply because more agents sounds more advanced.
